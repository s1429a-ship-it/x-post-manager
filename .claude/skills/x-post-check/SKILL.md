# X投稿文チェック

## いつ使うか
「なぜバズったか」のX投稿文（スレッド）を作り終えたら、ユーザーに渡す前に必ずこのチェックを通す。

## チェック項目（重要な順）
各項目を「はい／いいえ」で判定する。

1. 投稿に出てくる事実と数字は、すべて元の分析メモに書かれているか（メモにないものを足していないか）
   - 元の分析メモが無いときは「いいえ」とし、未解決として伝える
2. 数字（再生数・いいね数など）に、どの投稿の数字か、または確認日時が付いているか
   - NG例：「120万回再生」 → OK例：「120万回再生（10/5時点）」
3. 事実（動画で起きたこと）と解釈（なぜそうなったか）が、別々の文に分かれているか
4. 仮説を言い切っていないか（「〜だからバズった」ではなく「〜が要因の一つだった可能性が高い」になっているか）
5. 再生の要因（指が止まる・最後まで見る）と、反応の要因（いいね・コメント・保存・シェア）が、分けて書かれているか
6. 「場面 → 見た人の気持ち → 行動」の流れが、少なくとも1つ書かれているか
   - NG例：「Soraの映像がリアルで、クオリティが高いからバズった」
   - OK例：「冒頭で猫が転ぶ → 見た人は『え、大丈夫？』と心配になる → 続きが気になって最後まで見た」
7. 最後に「次の制作でどう使うか」が、教訓ではなく具体的な行動で1行以上あるか
   - NG例：「この動画から学べるのは、冒頭の引きの大切さです」
   - OK例：「再現するなら、冒頭2秒でキャラに小さなハプニングを起こす」
8. 4つの欲求（眺めたい・覗きたい・調べたい・触れたい）のうち2つ以上に当てはまり、その中に「触れたい（自分でも試したい）」が入っているか
   - 当てはまる欲求の名前と、それに当たる投稿の箇所を書き出してから判定する
9. 読者役での読み直し：AI動画に興味はあるが作ったことのない人として全文を読み直し、引っかかった箇所（意味が分からない言葉、話の飛び、長くて読む気が切れる所）を書き出す
   - 書き出したものが0件なら「はい」とする

## 「いいえ」があったとき
- 自分で直してから、全項目をもう一度チェックする
- 直せないもの（元の分析メモが無い、数字を確かめられない など）は直さずに残し、提出時に「未解決」としてユーザーに伝える
- 足りない事実や数字を、想像で埋めない

## 提出のしかた
投稿文の下に、次の形でチェック結果を付ける。

| # | 項目 | 結果 | メモ（直したこと／未解決の理由） |
|---|---|---|---|
| 1 | 事実と数字がメモにある | はい | |
| … | … | … | … |

未解決が1つでもあれば、表の上に「未解決：〇件」と書く。
Xへの投稿は、ユーザーのOKなしに行わない。
