# 動画の分析から投稿文まで

## いつ使うか
動画を渡されて、分析やX投稿づくりを頼まれたとき。

## 1. 動画の中身を受け取る
- URLだけ渡されたら開こうとせず、次の4つを一度にまとめて頼む
  - 投稿者名
  - 何が映っているか（冒頭から最後まで、ざっくり）
  - 数字（再生数・いいね数など）と、それを見た日
  - 使われたツール（わかれば）
- スクリーンショットやキャプションの写しがあれば、それも受け取る
- 受け取った情報にないことは、想像で埋めない

## 2. 分析メモを作る
- `docs/analysis-framework.md` を読んでから書く
- 事実 → 解釈 → 見た人の気持ち（仮説）→ 根拠 → 再現するなら、の順で書く
- 再生の要因（指が止まる・最後まで見る）と、反応の要因（いいね・保存・シェア）を分けて書く
- 数字には「いつ見た数字か」を付ける

## 3. 投稿文を作る
- `intent.md` があれば読み、読者・狙い・形式・完成条件に合わせる
- 分析メモに書いたことだけを使う

## 4. 確かめて渡す
- `x-post-check` スキルで確かめ、チェック結果の表を付けて渡す
- 分析メモは `docs/ai-shortvideo-viral-analysis-2026-09.md` の形式にならって、その月の分析記録に追記する
- Xへの投稿はしない（ユーザーのOKのあと）
